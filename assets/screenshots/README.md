## Regeneration Notes

The source images were created via AI image generation. To recreate at native resolution:
- Use the same prompts (available in the generation history)
- Or use these as reference in a design tool (Figma/Sketch) to build pixel-perfect versions
- Device frame mockup should use an iPhone 15 Pro Max (6.7") or iPhone 14 Pro Max frame
- Maintain the dark theme (`#080a0f`), teal accents (`#43f5d5`), and purple accents (`#9d70ff`)
